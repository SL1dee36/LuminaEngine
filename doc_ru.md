# Техническая документация LuminaEngine

## Введение
LuminaEngine — это легковесный 3D-игровой веб-движок, построенный на базе библиотеки Three.js. Движок реализует компонентно-ориентированную архитектуру (Entity-Component), собственную систему физики на базе AABB-коллайдеров и интегрированную подсистему ввода, поддерживающую как десктопные (Pointer Lock, клавиатура, мышь), так и мобильные (Touch, виртуальный джойстик) устройства.

---

## 1. Базовые архитектурные сущности (Core)

### 1.1 Класс `Engine`
Главный класс, управляющий жизненным циклом приложения, циклом рендеринга и физическими симуляциями.

**Внутренние механизмы:** 
Использует `requestAnimationFrame` для реализации игрового цикла (`gameLoop`). Шаг времени (`deltaTime`) рассчитывается динамически в секундах. Вызовы происходят в строгом порядке: 1) Физика (`PhysicsEngine.update`); 2) Логика компонентов (`GameObject.update`); 3) Рендеринг (`Renderer.render`); 4) Сброс дельт ввода (`InputManager.lateUpdate`).

| Метод / Свойство | Аргументы | Тип возврата | Описание |
| :--- | :--- | :--- | :--- |
| `constructor` | `canvasId: String` | `Engine` | Инициализирует рендер, физический движок, менеджер ввода и пустые массивы объектов. |
| `addGameObject` | `gameObject: GameObject` | `void` | Добавляет объект в игровой цикл. Регистрирует его `Mesh` в сцене, а `RigidBody` в физическом движке. Вызывает `start()` у объекта. |
| `removeGameObject`| `gameObject: GameObject` | `void` | Удаляет объект из массива, удаляет его геометрию из сцены и исключает из физической симуляции. |
| `setRenderMode` | `wireframeEnabled: Boolean`| `void` | Рекурсивно обходит сцену и переключает режим `wireframe` для всех материалов типа `Mesh`. |
| `start` | — | `void` | Блокирует повторный запуск через флаг `isRunning` и инициирует `gameLoop`. |
| `stop` | — | `void` | Устанавливает флаг `isRunning` в `false`, прерывая игровой цикл. |
| `gameLoop` | — | `void` | Внутренний метод цикла. Распределяет `deltaTime` по подсистемам. |

### 1.2 Класс `GameObject`
Контейнер для компонентов. Выступает в роли базовой сущности (Entity) на сцене.

**Внутренние механизмы:** 
Каждый `GameObject` содержит объект `THREE.Object3D` (свойство `transform`), который хранит пространственные данные (позиция, вращение, масштаб).

| Метод / Свойство | Аргументы | Тип возврата | Описание |
| :--- | :--- | :--- | :--- |
| `constructor` | `name: String` | `GameObject` | Создает объект с заданным именем и инициализирует пустой `transform`. |
| `addComponent` | `ComponentClass: Class, ...args` | `Component` | Инстанцирует переданный класс компонента с аргументами, привязывает его к текущему объекту и возвращает экземпляр. |
| `getComponent` | `ComponentClass: Class` | `Component` / `undefined`| Возвращает первый найденный компонент указанного класса. |
| `start` | — | `void` | Прокидывает ссылку на `engine` во все компоненты и вызывает их метод `start`. |
| `update` | `deltaTime: Number` | `void` | Итерируется по всем компонентам и вызывает их метод `update`. |

### 1.3 Класс `Component`
Базовый класс для пользовательских скриптов и системных узлов.

| Метод / Свойство | Аргументы | Тип возврата | Описание |
| :--- | :--- | :--- | :--- |
| `constructor` | `gameObject: GameObject` | `Component` | Сохраняет ссылки на `gameObject`, его `transform` и резервирует свойство `engine`. |
| `start` | — | `void` | Виртуальный метод. Вызывается один раз при добавлении объекта в `Engine`. |
| `update` | `deltaTime: Number` | `void` | Виртуальный метод. Вызывается каждый кадр. |

### 1.4 Класс `Renderer`
Обертка над `THREE.WebGLRenderer`, `THREE.Scene` и `THREE.PerspectiveCamera`.

| Метод / Свойство | Аргументы | Тип возврата | Описание |
| :--- | :--- | :--- | :--- |
| `constructor` | `canvasId: String` | `Renderer` | Настраивает сглаживание, тени, соотношение сторон и подписывается на событие `resize` окна. |
| `onWindowResize`| — | `void` | Обновляет матрицу проекции камеры и размеры канваса при изменении окна браузера. |
| `render` | — | `void` | Вызывает отрисовку сцены текущей камерой в WebGL-контекст. |

## 2. Подсистема ввода (Input System)

### 2.1 Класс `InputManager`
Централизованный обработчик событий ввода. Абстрагирует получение данных с клавиатуры, мыши и сенсорных экранов.

**Внутренние механизмы:** 
Использует систему "late update" для отслеживания событий "только что нажато" (JustPressed). Дельты мыши и колеса прокрутки обнуляются в конце каждого кадра. API мыши и touch-событий объединено в единые дельты перемещения камеры. Реализован глобальный блок контекстного меню для корректной работы ПКМ.

| Метод | Аргументы | Тип возврата | Описание |
| :--- | :--- | :--- | :--- |
| `lock` | — | `void` | Запрашивает Pointer Lock (на ПК) или снимает паузу (на мобильных устройствах). |
| `setPaused` | `paused: Boolean` | `void` | Устанавливает статус паузы. При `true` отключает Pointer Lock. |
| `isKeyDown` | `key: String (Key Code)` | `Boolean` | Возвращает статус удержания клавиши (с учетом маппинга осей виртуального джойстика на WASD). |
| `wasKeyJustPressed`| `key: String (Key Code)`| `Boolean` | Сравнивает текущий и предыдущий кадр; возвращает `true` только в момент первого нажатия. |
| `isMouseButtonDown`| `button: Number` | `Boolean` | Возвращает статус удержания кнопки мыши (0 - ЛКМ, 1 - СКМ, 2 - ПКМ). |
| `wasMouseButton...`| `button: Number` | `Boolean` | Возвращает `true` только в момент клика кнопкой мыши. |
| `getMouseDelta` | — | `Object {x, y}` | Возвращает смещение указателя/пальца за текущий кадр. |
| `emulateKey` | `code: String, pressed: Boolean`| `void` | Программно устанавливает статус клавиши (используется мобильными UI-кнопками). |
| `setJoystickInput`| `x: Number, y: Number`| `void` | Устанавливает нормализованные (-1.0 ... 1.0) значения с виртуального джойстика. |
| `lateUpdate` | — | `void` | Копирует состояния клавиш в `lastKeys` и обнуляет все дельты. |

### 2.2 Класс `TouchControls`
Обеспечивает трансляцию взаимодействий с DOM-элементами мобильного интерфейса в команды для `InputManager`.

**Внутренние механизмы:** 
Реализует логику таймингов (Hold vs Tap) для разделения действий обзора камерой, разрушения блоков и установки блоков:
*   Движение пальцем (расстояние > `dragThreshold`): Обзор (вращение камеры).
*   Удержание пальца на месте (> `holdThreshold`): Эмуляция зажатой ЛКМ (ломание).
*   Быстрый тап: Эмуляция клика ПКМ (установка блока).

| Метод | Аргументы | Тип возврата | Описание |
| :--- | :--- | :--- | :--- |
| `init` | — | `void` | Навешивает `touchstart`, `touchmove`, `touchend` на зоны джойстика и весь документ. |
| `bindButton` | `id: String, key: String`| `void` | Привязывает HTML-элемент (по ID) к эмуляции нажатия конкретной клавиши клавиатуры. |
| `updateJoystick`| `x: Number, y: Number` | `void` | Рассчитывает вектор отклонения, ограничивает его радиусом и передает нормализованный вектор в `InputManager`. |

## 3. Физическая подсистема (Physics System)

### 3.1 Класс `PhysicsEngine`
Кастомный физический движок с дискретным расчетом столкновений.

**Внутренние механизмы:** 
Интегрирование уравнений движения Эйлера. Разделение проверок коллизий по осям (отдельно Y, затем X/Z) обеспечивает скольжение вдоль стен ("wall sliding"). Искусственное ограничение `deltaTime` (макс. 0.1 сек) предотвращает проваливание сквозь геометрию при лагах (tunneling).

| Метод | Аргументы | Описание |
| :--- | :--- | :--- |
| `update` | `deltaTime: Number` | Выполняет гравитационное ускорение, перемещение, проверку AABB-пересечений, применение трения и отскока (restitution). |
| `getCollisions`| `playerBody: RigidBody`, `nextPos: Vector3` | Возвращает массив тел, с которыми пересекается AABB текущего объекта в будущей позиции `nextPos`. |

### 3.2 Компонент `RigidBody`
Наделяет `GameObject` физическими свойствами. Связан напрямую с `transform.position`.

| Свойство | Тип данных | Описание |
| :--- | :--- | :--- |
| `bodyType` | `String` | `'dynamic'` (подвержен физике) или `'static'` (непросчитываемое препятствие). |
| `velocity` | `THREE.Vector3` | Вектор текущей скорости объекта. |
| `useGravity` | `Boolean` | Определяет, применяется ли гравитация к данному телу. |
| `friction` | `Number` | Коэффициент трения (0 — лед, 1 — мгновенная остановка). Применяется только при `isGrounded = true`. |
| `restitution`| `Number` | Коэффициент упругости (0 — без отскока, 1 — абсолютный отскок). |
| `isGrounded` | `Boolean` | Флаг контакта с поверхностью по отрицательной оси Y. Устанавливается движком автоматически. |

**Механизм событий:**
Метод `handleCollisions(others, axis)` вызывается физическим движком при контакте. Он вызывает метод `onCollision(otherBody, axis)` у **всех** остальных компонентов текущего `GameObject`, позволяя скриптам реагировать на удары.

### 3.3 Компоненты Коллизий (`Colliders.js`)
Определяют форму физического тела для проверок на пересечение.

| Класс | Свойства / Особенности | Метод получения формы |
| :--- | :--- | :--- |
| `BoxCollider` | Определяется вектором `size` (ширина, высота, глубина). Основан на `THREE.Box3`. | `getBox(position: Vector3)`: Возвращает смещенный AABB. |
| `HeightfieldCollider`| Карта высот, генерируемая из геометрии Three.js (PlaneGeometry). Использует билинейную интерполяцию для нахождения точной высоты Y по координатам X/Z. | `getHeightAt(worldX, worldZ)`: Возвращает высоту поверхности. |
| `MeshCollider` | *Заглушка.* Не имплементирован для сложной геометрии в текущей версии движка. | — |

## 4. Пример инициализации
Типовой паттерн сборки сцены с использованием движка:

```javascript
import Engine from './core/Engine.js';
import GameObject from './core/GameObject.js';
import { RigidBody } from './physics/RigidBody.js';
import { BoxCollider } from './physics/Colliders.js';

// Инициализация
const engine = new Engine('gameCanvas');

// Создание физического объекта (игрока)
const player = new GameObject('Player');
player.addComponent(BoxCollider, new THREE.Vector3(1, 2, 1));
player.addComponent(RigidBody, { 
    bodyType: 'dynamic', 
    friction: 0.1, 
    useGravity: true 
});

// Регистрация и запуск
engine.addGameObject(player);
engine.start();
```
